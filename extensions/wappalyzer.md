## What it does
Shows what any website is built with: framework, CMS, analytics, JavaScript libraries, hosting, payments. Exports to CSV.

## How we use it
- Study reference sites: are they on Next.js? Using GSAP, Lenis, Three.js?
- Client audits: see their current stack before we pitch a rebuild.
- Check our own launches show up as Next.js on Vercel or Netlify.

## Tips
- It reads every page you visit. In `chrome://extensions` > Details, set **Site access** to **On click** if you don't
  need it all the time.
- Detection is a best guess. Confirm in DevTools before quoting it to a client.
