# seative-toolkit

The team hub: our tools, the stack we build every website with, setup and deploy guides, AI prompts, motion learning
links and short team rules. Everything links to the source; nothing here is a copy of someone else's code.

## Start here

1. [guides/onboarding.md](guides/onboarding.md): install everything on a new computer (Node.js first)
2. [guides/github-setup.md](guides/github-setup.md): GitHub, branches and pull requests
3. [prompts/website-create-prompt.md](prompts/website-create-prompt.md): start a new website
4. [learn/motion-presets.md](learn/motion-presets.md): learn motion and easing
5. [links.md](links.md): every link in one place

## Our standard website stack

Next.js · GSAP (ScrollTrigger, SplitText) · Lenis · Three.js · Rive for interactive pieces · DialKit for live tuning
in development · GitHub · Vercel (default) or Netlify.
