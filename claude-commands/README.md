# Claude commands

Our shared Claude Code commands live in their own repo so there is one version to install, update and review:

**[RnD-Products/go-commands](https://github.com/RnD-Products/go-commands)**: `go pr`, `go update`, `goapp update`.
Install and use: [repos/go-commands.md](../repos/go-commands.md).

Adding a new shared command or skill? Add it to go-commands (`skills/<name>/SKILL.md`) through a pull request, not here.
