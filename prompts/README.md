## Where to find more
- [Motion examples](https://motion.dev/examples): free animation snippets for React, JavaScript and Vue.
- [Scrolltide components](https://www.scrolltide.co/components): animated component prompts (paid plans). **Link only**:
  never paste paid prompts into this repo.
- [GetLayers AI tools](https://www.getlayers.ai/tools): free tools that end in a prompt (SVG to 3D, gradients,
  shaders), also over MCP.

## Rules
- Adapt every outside prompt to our stack, our `motion.ts` presets and DialKit before using it.
- When a prompt works well, save our version here with a link to where it came from.
- Repeating the same rules in every prompt? They belong in the [Claude motion skill](../stack/claude-motion-skill.md).
